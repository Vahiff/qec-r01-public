# QEC-R01 — Phase 2 research execution report

**Date:** 2026-10-25  |  **Scope:** 3-qubit repetition code, Pauli-X noise only, ideal syndrome measurements.  
**Methods status:** Phase-2 primary H1 calibration PASS in the registered single condition; QuTiP BLOCKED; arbitrary X/Z single-error correction with three physical qubits MATHEMATICALLY IMPOSSIBLE. This report is not a peer-reviewed research publication.

## Step 1 — finite-sample calibration, executed

Code: `src/calibration.py`. Data: `results/calibration.json`. Actual stdout and timing: `results/calibration.log`.

- Physical noise: independent X on each of three qubits with `p=0.02`, plus a simultaneous `(X0,X1)` event with true `b=0.04`. Independent events combine by XOR.
- Calibration: known `|000>` states and computational-basis measurement of physical bit 0; marginal `q0=p+(1-2p)b=0.0584`. Estimate `b_hat=clip((k/N-p)/(1-2p), 0, 0.08)` from `k` observed excitations.
- For each `N in {0,50,200,1000,5000}`, 2000 independent calibration datasets are generated by a seeded pseudorandom Bernoulli sampler. `N=0` uses the minimum-weight decoder. The decoder is a syndrome-wise MAP table for the fitted distribution. Fix random seed `20261025 + N`.
- No calibration sample is reused for assessing the logical failure rate. Instead the conditional rate for each chosen decoder is computed **exactly**, using all eight X-masks under true `b=0.04`. Uncertainty bands are 95% Wilson intervals for selecting the oracle branch, propagated into mean LER; these quantify replicate-selection sampling, not physical-device uncertainty.

## Step 3 — impossible-code trap

**NO: cannot encode an unknown logical qubit into three physical qubits with perfect correction of arbitrary single-qubit X, Z, and Y errors.** A code correcting arbitrary errors on one site has distance `d >= 3`. The **quantum Singleton bound** for an `[[n,k,d]]` quantum code states `n-k >= 2(d-1)`. For `n=3`, `k=1`, `d=3`, this requires `2 >= 4`, false. The smallest such code uses five qubits (`[[5,1,3]]`). A 3-qubit repetition code corrects single X flips or, in the conjugate basis, single Z flips — not both for arbitrary unknown encoded qubits. The 9-qubit Shor code should not be confused with this three-qubit repetition code.

**No `src/shor3_test.py` is written.** No pretend quantum experiment is presented; a theoretical no-go result obviates the demanded impossible implementation.

Evidence: D. Gottesman, *Quantum Error Correction*, Chapter on Quantum Singleton bound, https://www.cs.umd.edu/~dgottesm/QECCbook-2024.pdf ; Laflamme et al., *Perfect Quantum Error Correcting Code*, Phys. Rev. Lett. 77, 198 (1996), https://doi.org/10.1103/PhysRevLett.77.198 .
